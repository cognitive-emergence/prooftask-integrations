# n8n-nodes-prooftask

Anonymous public delivery template search and exact-version reads, usable in workflows and as an AI Agent tool. No account, credential or business write.

Search a delivery scenario, then pass the returned slug and version to Get. Retain the digest and review scope, completion criteria and evidence with the user. Templates are editable examples, not quality certification, acceptance, signatures or payment proof.

Private workflow integration uses the separate scoped Agent API and the companion n8n prepare-job, send-job and events workflows. See https://prooftask.com/developers and https://github.com/cognitive-emergence/prooftask-integrations/tree/main/n8n.

This source candidate is not evidence of npm publication or n8n Cloud verification. Build, lint, real engine execution and marketplace review must be recorded before claiming those states.
